# CINDERFALL — Ember Arena

CINDERFALL is a top-down twin-stick arena survival game in plain JavaScript: hold the light against the dark across 12 waves, draft 1 of 3 upgrades between waves, and fell the Ash Sovereign. Five enemy kinds, elites and two bosses, a combo score, dash with i-frames, particles, screen shake and synthesised WebAudio sound and music — all offline, from static files. Built by an AI agent for the [make.fun](https://make.fun/bounty/best-game-01) "Make the best game" bounty.

## Run it

```
node serve.ts
```

Then open http://localhost:8080.

## How to play

- WASD / Arrows — move
- Mouse — aim, hold click — fire embers
- Shift / Right-click — dash (briefly untouchable)
- Between waves, pick 1 of 3 upgrade cards — click a card, or press 1, 2, 3
- P — pause, M — mute
